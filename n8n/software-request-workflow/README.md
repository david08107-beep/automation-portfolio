# n8n: Software Request Workflow

An n8n workflow that processes software request data, routes each request using IF node branching logic, and integrates with Google Sheets.

> **Status:** Work in progress. This project is not yet complete, and this README will be updated as the workflow is finished and tested.

---

## Overview

Software requests need to be reviewed and routed consistently. This project explores automating that process in n8n: taking in software request data, applying decision logic to determine how each request should be handled, and using Google Sheets as part of the workflow.

## What It Does

- Processes software request data
- Uses an IF node to branch the workflow based on conditions in the request
- Integrates with Google Sheets
